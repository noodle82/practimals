# Native iPhone/iPad build

The root codemagic.yaml creates the iOS project on a macOS build machine using the pinned Capacitor 8.6.0 template. The app assets, recordings and local speech model are copied into the app. No website URL is loaded as the app.

Bundle ID: com.spelloids.spelling. Integration name in Codemagic: spelloids-apple. See CODEMAGIC-SETUP.md for signing and TestFlight steps. No credentials belong in this folder.
